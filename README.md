# 🐸 Бот-сканер TOAD

Современный Telegram-бот для проверки пользователей, хранения жалоб и управления базой данных.

---

# 🚀 Возможности

- 🔍 Проверка пользователей
- 📝 Добавление жалоб
- 👤 Профиль пользователя
- 📊 Статистика
- 🛡️ Административная панель
- ⚙️ ФШМ-сенарии
- 💾 Работа с базой данных SQLite
- 🌐 Веб-интерфейс администратора

---

# 🛠️ Используемые технологии

- Питон 3
- айограмма 3
- SQLite
- python-dotenv
- HTML
- CSS
- JavaScript

# ⚡ Установка

```баш
git клон https://github.com/Pack6712/TOAD-Scanner-Bot.git
cd TOAD-Сканер-Бот
pip install -r требования.txt
```

Создайте файл `.энв`

```энв
BOT_TOKEN=ВАШ_BOT_TOKEN
ADMIN_ID=ВАШ_ADMIN_ID
СЕКРЕТ_АДМИНИСТРАТОРА=ВАШ_СЕКРЕТ_АДМИНИСТРАТОРА
```

Запуск:

```баш
python bot.py
```
